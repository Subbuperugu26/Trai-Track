# Employee Tracker React

React + Vite version of the Employee Tracker.

## Features

- Home
- Employee Tracker form
- Google Apps Script submission
- Dashboard
- Batch performance
- Employee performance table
- Top 7 employees only in Employee Ranking graph
- Reports
- About
- Responsive navbar

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
